# FINTECH PARTY 3.0 — Bangkok

P2Private × FT Community · 8 декабря · Anantara Siam Bangkok Hotel.

**Сайт:** https://sard-io.github.io/fintech-party-3-bangkok/

Адаптивный сайт на HTML, CSS и JavaScript. Все изображения, логотипы и видео находятся в репозитории. Для запуска не нужны сборка, Node.js или сторонние сервисы.

## Локальный просмотр

Скачайте репозиторий и откройте `index.html` в современном браузере. Сохраните рядом `styles.css`, `script.js` и папку `assets`.

На сайте два видео: локация у бассейна и финальный ролик Fridman Tower. Оба запускаются кнопкой воспроизведения; доступны звук, перемотка и полный экран. При запуске второго первое автоматически останавливается. На сайте оставлено только управление видео, без лишних кнопок и внешних ссылок.

## Файлы

- `index.html` — содержание сайта.
- `styles.css` — оформление и адаптация под телефон.
- `script.js` — управление видео и анимации появления.
- `assets/` — логотипы, фотографии, фотомонтажи и полный видеоролик.
- `.nojekyll` — публикация готовых статических файлов без обработки Jekyll.

## GitHub Pages

Публикация настроена из корня ветки `main`. Изменения в `main` автоматически обновляют сайт после завершения публикации GitHub Pages.

Все пути к CSS, JavaScript и медиа относительные, поэтому сайт работает по адресу проекта GitHub Pages и при локальном просмотре.

Мобильная обложка показывает фотографию отеля целиком, отдельно от текста. Указано 200–400 участников. Блок партнёрства показывает MELBET как основного спонсора Fridman Tower и место для основного спонсора FINTECH PARTY 3.0; размещение ограничено днём вечеринки.
